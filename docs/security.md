# Security Stack

CapsuleBay integrates layered security measures to ensure the integrity and safety of deployments. The security stack consists of various tools and processes for vulnerability scanning and secret management.

## Overview of Security Measures

CapsuleBay employs a multi-layered approach to security, focusing on both pre-deployment and deployment phases. The following tools and processes are utilized:

| Layer | Tool | Purpose |
|-------|------|---------|
| **GitHub Actions (pre-merge)** | **Trivy** | Scans built images for vulnerabilities, focusing on HIGH and CRITICAL severity issues. |
| | **Snyk** | Scans Dockerfiles for dependency vulnerabilities (CVEs). |
| **Jenkins (pre-deploy)** | **Trivy CLI** | Rescans the final image before deployment to ensure no new vulnerabilities have been introduced. |
| **Vault** | **HashiCorp Vault** | Securely manages and delivers secrets required for deployments. |
| **Discord** | **Webhook alerts** | Sends notifications regarding the success or failure of builds, including links to the build and relevant timestamps. |

## Detailed Security Processes

### GitHub Actions

1. **Image Building and Scanning**:
   - On every push or pull request, GitHub Actions automatically builds capsule images.
   - Trivy scans these images for vulnerabilities, specifically targeting HIGH and CRITICAL severity levels.
   - Snyk scans Dockerfiles for potential dependency vulnerabilities.

2. **Artifact Management**:
   - Scan reports generated by Trivy and Snyk are uploaded as artifacts for review, ensuring that all commits are secure and compliant before they reach the deployment stage.

### Jenkins

1. **Controlled Deployments**:
   - Jenkins handles the deployment of capsule images within a controlled environment, ensuring that only validated images are deployed.
   - Before deployment, Jenkins rescans the built images using Trivy to confirm that no vulnerabilities are present.

2. **Secret Management**:
   - Secrets required for deployment are dynamically retrieved from HashiCorp Vault, ensuring that sensitive information is not hard-coded into the deployment scripts.

3. **Deployment Notifications**:
   - Upon completion of the deployment process, Jenkins sends notifications to a designated Discord channel, providing information about the service, environment, build link, duration, and timestamp.

## Conclusion

The security stack of CapsuleBay is designed to provide comprehensive protection throughout the CI/CD pipeline. By integrating vulnerability scanning and secure secret management, CapsuleBay ensures that deployments are both reliable and secure.
